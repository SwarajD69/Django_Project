# Portfolio Website 💼

A simple personal portfolio website built with **Django**. Showcases projects, skills, and experience with a clean and responsive design.

---

## Requirements

- Python 3.8+
- pip
- SQLite (built-in with Python)

---

## Setup & Run

```bash
git clone https://github.com/SwarajD69/Django_Project.git
cd Django_Project
python3 -m venv venv
source venv/bin/activate       # Linux/macOS
venv\Scripts\activate          # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open in browser: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

---

## Features

* Display projects, skills, and experience
* Responsive templates and static files
* Manage content via Django admin panel
